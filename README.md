# Speek2Me

Speek2Me is a macOS menu-bar app that speaks to you about your terminal AI sessions. When
Claude Code or Codex CLI finishes a turn, it reads the final answer aloud, condensed. When a
session needs you (a permission prompt, a question, an idle nudge), it says so. Streaming
output, thinking and tool chatter stay silent. It is the sibling of
[Talk2Me](https://github.com/Moen01/talk2me): Talk2Me turns your speech into text for the
machine, Speek2Me turns the machine's final words into speech for you.
