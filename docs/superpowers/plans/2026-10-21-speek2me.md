# Speek2Me Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS menu-bar app that speaks the final answer of each Claude Code or Codex CLI turn, and speaks when a session needs the user.

**Architecture:** Hooks in each tool run a tiny bundled CLI (`speek2me-hook`) that normalizes the hook JSON into a `SessionEvent` file in an inbox directory. The app watches the inbox, condenses `turnComplete` text with the user's Claude backend (Claude Code CLI, API key, or Off), and speaks through ElevenLabs with an Apple fallback. All logic lives in `Speek2MeCore`; the app target is wiring, settings and the setup guide.

**Tech Stack:** Swift 6.2, SwiftPM, macOS 26, AppKit + SwiftUI, AVFoundation, URLSession, Swift Testing. No third-party packages.

**Spec:** `docs/superpowers/specs/2026-10-21-speek2me-design.md`

## Global Constraints

- `swift-tools-version: 6.2`, `platforms: [.macOS(.v26)]`. Core and hook targets in Swift 6 mode; app target `swiftLanguageMode(.v5)`.
- No third-party Swift packages.
- Hook CLI: always exit 0, never write to stdout, finish under 50 ms, honour `SPEEK2ME_SUPPRESS=1`.
- Config edits: additive, idempotent, backup named `<file>.bak-speek2me-<timestamp>` beside the original, atomic write, refuse on invalid existing content.
- Secrets only in the Keychain, service `dev.speek2me.Speek2Me`.
- Hook handler shape: `{"type":"command","command":"<cmd>","timeout":5,"async":true}`.
- Claude Notification matcher: `permission_prompt|elicitation_dialog|elicitation_url_dialog|agent_needs_input|idle_prompt`.
- Claude condenser spawn adds `--settings {"disableAllHooks":true}` and env `SPEEK2ME_SUPPRESS=1`.
- ElevenLabs: `POST /v1/text-to-speech/{voice_id}?output_format=mp3_44100_128`, header `xi-api-key`, body `{text, model_id}`, default model `eleven_flash_v2_5`, text capped at 2,500 characters.
- Defaults: condense on, Haiku 5.5, 3 sentences, condense timeout 15 s, ElevenLabs timeout 10 s, inbox stale age 120 s, idle nudges on, quiet-when-focused off.
- Commit messages: Conventional Commits; end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

- A `last_assistant_message` of 50 KB: the raw condenser keeps three sentences and the ElevenLabs request body carries at most 2,500 characters. (Tasks 5, 6)
- A `notification_type` the app does not know: parser returns nil, nothing is spoken, nothing crashes. (Task 2)
- A `~/.claude/settings.json` with no `hooks` key, or `hooks.Stop` as an empty array: install creates the structure and other keys survive. (Task 8)
- A half-written or corrupt inbox file: drain skips it, deletes it, and still returns the good events. (Task 3)
- ElevenLabs answers 401 at speak time: Apple speaks the same text and the menu shows why. (Task 6)
- `cwd` of `/` or empty: the project name is "a session", never an empty prefix. (Task 1)
